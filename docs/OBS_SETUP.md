# OBS 集成指南

LiveSub 的字幕窗口是一个**无边框、置顶、半透明背景**的 Direct2D 窗口，
OBS 用"窗口捕获"即可叠加到直播画面。

## 方法一：窗口捕获（推荐）

1. 启动 LiveSub（`.\scripts\run.ps1`）
2. OBS 中：来源 → **+** → **窗口捕获**
3. 窗口列表选择 **LiveSub 字幕**（或 "LiveSub 字幕窗口"）
4. 捕获方式建议 **Windows 10 (1903+) / WGC**（OBS 31+ 效果最佳）

### 透明度说明

- 字幕窗口默认带 **半透明黑色背景**（`ui.bg_color = #C0000000`），OBS 各种捕获方式都能正确显示
- 如需**完全透明背景**（只显示文字）：
  - OBS ≥ 31 且使用 WGC 捕获方式时，勾选窗口捕获属性里的 **"允许透明度" (Allow transparency)**
  - 同时把 `config.ini` 的 `ui.bg_color` 改为 `#00000000`
- 老版本 OBS 窗口捕获不支持透明，会显示黑底——保持半透明背景即可（直播中反而更清晰）

### 常见问题

| 问题 | 解决 |
|---|---|
| 捕获到黑框 | 用 WGC 捕获方式；或把 `bg_color` 改回半透明黑 |
| 窗口列表里找不到 | 确认 LiveSub 在运行；勾选"窗口捕获"里的"显示未捕获的窗口" |
| 字幕被遮挡 | 窗口始终置顶；也可在 OBS 里把字幕源放到最上层 |

## 方法二：文本文件（备选）

LiveSub 默认把当前字幕写入 `subtitles.txt`（`output.write_text`）：

1. OBS → 来源 → **+** → **文本 (GDI+)**
2. 勾选 **从文件读取**，选择 `subtitles.txt`
3. 文本文件每秒刷新，字幕实时更新（延迟约 1 秒）

也可开启 `output.write_srt = true` 生成 SRT 文件（供后期剪辑）。

## 直播建议

- 字幕样式：白字 + 半透明黑底、加粗、大字号（42+），文字与背景对比度越高越清晰
- 位置：默认屏幕底部居中；用 `ui.window_x/y` 微调，或 OBS 里直接拖动字幕源
- 若有弹幕/其他元素遮挡，可把字幕源放大缩小（窗口捕获支持自由缩放）
- 开启 `ui.click_through` 可让鼠标穿透字幕窗口（设置窗或 config.ini）
